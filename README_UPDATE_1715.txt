ACCOMMODATION TYPE
- Planner now has: Geen voorkeur / Camping / Hotel-B&B.
- Choice is stored with the trip.
- Camping restricts live OSM accommodation searches to camp_site/caravan_site.
- Hotel/B&B restricts searches to hotel/guest_house/hostel/motel.
- Nominatim fallback follows the same choice.
- Wrong accommodation category receives a very large ranking penalty.
- The selected type is carried into every overnight recommendation.
